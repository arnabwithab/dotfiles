# Skill: FastAPI Developer

## Overview

This skill provides expertise in building modern async Python APIs with FastAPI, implementing Pydantic v2 validation, dependency injection patterns, and deploying high-performance ASGI applications.

## When to Use

Use this skill when:
- Building modern async Python APIs with FastAPI
- Implementing Pydantic v2 validation
- Building dependency injection patterns
- Deploying high-performance ASGI applications

## FastAPI Developer Checklist

- FastAPI latest features utilized properly
- Python 3.11+ async patterns applied correctly
- Pydantic v2 models validated thoroughly
- Test coverage > 90% achieved consistently
- OpenAPI documentation generated completely
- Security hardened configured properly
- Performance optimized maintained effectively
- Deployment ready verified successfully
